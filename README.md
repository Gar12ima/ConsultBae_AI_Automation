# ConsultBae AI Automation

## Project Overview

This project is developed as part of the ConsultBae AI Automation Assignment.

The objective of this project is to create an automated system for database creation, data processing, analysis, and audio collection workflow.

---

# Task 1: Database Creation and Analysis

## Objective

The goal of Task 1 was to create a structured database system and perform verification and analysis on the provided data.

---

## Implemented Components

### Database Creation
- Created SQLite database.
- Designed required tables and columns.
- Stored structured records for further analysis.

### Data Verification
- Verified database structure.
- Checked table creation and stored records.

### Data Analysis
- Performed matching and analysis operations.
- Generated analysis output files.
