# ConsultBae AI Automation Assignment

## Project Overview

This project is developed as part of the ConsultBae AI Automation Assignment.

The objective of this project is to implement database creation, data processing, workflow automation, audio collection, and final documentation using Python, N8N, Streamlit, and SQLite.

---

# Task 1: Database Creation and Analysis

## Objective

Created a structured database system by combining multiple datasets and performing data analysis.

## Implementation

- Loaded multiple CSV datasets.
- Performed data inspection and preprocessing.
- Identified duplicate records.
- Created SQLite database.
- Verified database tables and records.

## Technologies Used

- Python
- Pandas
- SQLite

---

# Task 2: N8N Workflow Automation

## Objective

Created an automation workflow for duplicate person matching using N8N.

## Implementation

- Designed N8N workflow.
- Configured workflow nodes.
- Implemented duplicate matching automation.
- Tested workflow execution successfully.

## Technologies Used

- N8N
- JSON Workflow
- Automation Logic

---

# Task 3: Audio Collection Application

## Objective

Developed an audio collection application to collect and analyze user audio submissions.

## Implementation

- Created Streamlit based application.
- Added user details input.
- Added audio upload functionality.
- Extracted audio features:
  - Duration
  - Sample Rate
  - Bitrate
  - Loudness
- Stored audio records in SQLite database.

## Technologies Used

- Python
- Streamlit
- Librosa
- SQLite
- NumPy
